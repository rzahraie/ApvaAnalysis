# APVA Analysis

Auction Process / Price Volume Analysis (APVA) research environment.

This repository contains:

- Python/Jupyter-based statistical analysis
- Visualization notebooks
- CSV outputs generated by the NinjaTrader 8 APVA engine
- Exploratory auction-state research
- Transition and motif analysis

## Architecture

The project is intentionally split into two repositories:

### 1. NinjaTraderFiles

Real-time deterministic extraction layer.

Responsibilities:

- Bar-by-bar state classification
- Auction-state transitions
- Persistence tracking
- Incubation metrics
- Expectancy metrics
- CSV generation/export

This layer is implemented in NinjaScript/C#.

### 2. ApvaAnalysis

Offline research and statistical-analysis layer.

Responsibilities:

- Data exploration
- Visualization
- Correlation analysis
- Motif extraction
- Clustering
- Regime research
- Probability surface analysis
- Feature ranking/reduction

This layer is implemented in Python/Jupyter.

## Current Workflow

1. Run APVA engine inside NinjaTrader 8.
2. Generate xApvaV01*.csv outputs.
3. Copy/export CSVs into this repository.
4. Load CSVs in Jupyter notebooks.
5. Analyze:
   - state transitions
   - incubation quality
   - transition expectancy
   - trajectory motifs
   - persistence
   - conditional probabilities
6. Validate findings.
7. Port validated logic back into the NT8 engine.

## Current Research Direction

The project has evolved from:

- direct automation of Jack Hershey PVA concepts

into:

- generalized latent auction-state inference.

Current emphasis:

- probabilistic state transitions
- incubation quality
- entropy vs structure
- trajectory motifs
- directional continuation expectancy
- state persistence
- latent auction mechanics
